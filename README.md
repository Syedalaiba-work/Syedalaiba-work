## Focus areas

- **Multi-tenant isolation:** tenant boundaries enforced by the platform, not
  remembered per query
- **Real-time systems:** live agent and call state, low-latency voice turns
- **Event-driven integrations:** HMAC-signed webhooks, retries with backoff,
  idempotent delivery
- **Telecom compliance:** do-not-call suppression, recording disclosure,
  licence-aware routing
